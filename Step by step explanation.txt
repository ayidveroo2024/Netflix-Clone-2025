NOTE  - TAKE AWAY MESSAGE




Create React App (CRA) → only recognizes env vars that start with REACT_APP_.

Vite → only recognizes env vars that start with VITE_.

So in your project (which is Vite), you cannot use process.env.REACT_APP_.... That’s CRA-specific.
Vite’s bundler will never replace REACT_APP_ variables, which is why you kept seeing process is not defined.

⚡ Your options

If you want to keep using Vite (recommended — it’s faster & modern):
You must rename your variable to VITE_API_KEY and use import.meta.env.VITE_API_KEY.
👉 Vite has no option to make REACT_APP_ work.

If you really want to keep REACT_APP_ syntax:
You’d have to migrate back to Create React App instead of Vite. CRA is the only toolchain that supports REACT_APP_.

Downside: CRA is slower and no longer the default recommendation by React docs.
